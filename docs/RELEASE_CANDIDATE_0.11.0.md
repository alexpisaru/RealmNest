## 1. Release audit (15 October 2026, before any change)

### Build and run-time dependencies outside `src/`

- `tools/charpipe/cast/{looks,palette}` — imported by the app.
- `docs/{CAPABILITIES,CHAT,CONNECTIONS,FILES,KNOWLEDGE,MEMORY,MCP,PROVIDERS,RUNTIME,SKILLS,TOOLS,UI_UX}.md` and `README.md` — bundled as the built-in Knowledge base.
- `package.json` — the app version (`src/version.ts`).
- `public/baked/*`, `public/home/*` — loaded at run time; `src/tests/baked.test.ts` reads them.
- `tools/charpipe/*` — imported by `src/tests/charpipe.test.ts`.

### Secret scan

Patterns: Anthropic, OpenAI, OpenRouter, GitHub, Telegram, Slack, AWS keys, JWTs, private keys, Bearer literals, `.env` / credential files. **No real secret.** The 14 matches are fake test fixtures (alphabet sequences, `…SECRET`) in `src/tests/*` and `src-tauri/src/mcp/tests.rs`, kept because they test redaction. No `.env`, `.pem`, `.pfx` or credential export anywhere. The folder has no Git history, so nothing was ever committed.
